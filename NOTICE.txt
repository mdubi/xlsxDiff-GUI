- Created a Windows GUI with batch queue, cancellation, progress and logging.
- Added optional whole-number and percentage replacement highlighting.
- Added bilingual English/Polish GUI with switching at run time.
- Created and integrated a multi-size icon into GUI/Windows executables.
- Added validation/safety fixes, tests, reproducible packaging tools, and docs.
- Enabled XLSM input workbook comparison (no VBA processing; output XLSX).
